# BRAHMAN

Interactive 3D Solar System visualization built with React, Three.js, and Vite.

## Features

- 8 planets with accurate orbital speeds and rotations
- Sun with pulsing glow and corona effect
- Asteroid belt between Mars and Jupiter
- Earth atmosphere glow
- Saturn rings and Earth moon
- Starfield with milky way background
- Dust particles floating in space
- Bloom post-processing for realistic lighting
- Click any planet to focus the camera
- Search bar with planet autocomplete (Ctrl+K)
- Loading screen with progress bar
- Hover tooltips showing planet data (distance, diameter, day length, moons)
- Orbit trails behind each planet

## Tech Stack

- React 19
- Three.js via @react-three/fiber
- @react-three/drei (helpers)
- @react-three/postprocessing (bloom)
- Vite 8

## Getting Started

```bash
npm install
npm run dev
```
